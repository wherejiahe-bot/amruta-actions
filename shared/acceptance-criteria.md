# amruta-daily-push 审核标准

## 审核检查项（全部必须通过）

### P0 检查项（不通过则阻止发送）

1. **翻译来源判定** — 必须优先使用 F盘官方翻译文档
   - 找到官方翻译 → [OK]，显示文档名
   - 未找到 → [FAIL]

2. **英文原文保真** — 邮件英文 = amruta.today 抓取原文
   - 逐字符比较，不允许任何增减改
   - 使用句子集合排序比较（排除标题段落）

3. **排版对齐** — 必须是三种对齐模式之一
   - 1:1（一句英文对一句中文）
   - N:1（多句英文对一句中文）
   - 1:N（一句英文对多句中文）
   - **禁止**：粘成一坨（一大段英文+一大段中文）
   - **禁止**：重复模式（英文一段中文一段英文一段中文...）

4. **官方翻译截取** — 只截取与抓取英文对应的中文
   - 从 amruta.today 抓取的英文只有 1-3 个段落
   - 去官方翻译文档中只取对应的那部分中文
   - **禁止**：截取官方翻译文档的全部中文段落
   - **禁止**：出现多余的中英文段落

5. **标题翻译** — 中文标题来自英文标题翻译
   - 优先用官方翻译文档中的对应关键词
   - 没有的用阿里云翻译
   - **禁止**：直接使用英文标题

6. **底部链接** — 只留两个链接
   - Link 1: https://amruta.today/
   - Link 2: sahaja.live source URL
   - **禁止**：附加翻译来源说明区块

### P1 检查项

6. **结构完整性** — 标题、日期、分隔线、链接完整
7. **英中交替** — 英文和中文交替排列
8. **中文非空** — 无空中文段落
9. **翻译通顺度** — 翻译长度分布正常

## 审核结果

- 所有 P0 通过 → [PASS] 可以发送
- 任一 P0 不通过 → [FAIL] 阻止发送
