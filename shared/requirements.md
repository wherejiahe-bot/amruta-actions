# amruta-daily-push 需求文档

## 核心规则（铁律）

### 1. 标题翻译规则
- 邮件中文标题必须从 amruta.today 抓取的英文标题翻译而来
- 翻译方法：从官方中文翻译文档中找到英文标题对应的关键词，用官方翻译的那部分
- 官方翻译中没有的词，才用阿里云翻译补充
- **禁止直接用 amruta.today 的英文标题作为中文标题**

### 2. 排版规则（三种对齐模式）
邮件中英文和中文必须以下列三种形式之一对齐排列，**禁止粘成一坨**：
- **1:1** — 一句英语对一句中文
- **N:1** — 多句英语对一句中文
- **1:N** — 一句英语对多句中文

禁止多对多模糊对应（即禁止一大坨英文后面跟一大坨中文）。

### 2.1 官方翻译截取规则（铁律）
- 从 amruta.today 抓取到的英文只有一部分（可能只有 1-3 个段落）
- 去 F盘官方翻译文档中，**只截取与抓取到的英文对应的那部分中文**
- **禁止截取官方翻译文档的全部中文段落**
- 具体步骤：
  1. 从 amruta.today 抓取英文原文
  2. 在官方翻译文档中找到与抓取英文对应的英文段落
  3. 只取该英文段落对应的中文段落
  4. 其余中文段落不使用

### 3. 不重复规则
- 英文和中文各只出现一次
- **禁止**：英文一段、中文一段、英文又一段、中文又一段的重复模式
- 正确模式：每对（pair）只包含一组英文+一组中文，不重复

### 4. 英文原文保真规则
- 邮件中的英文部分必须完全等于 amruta.today 抓取原文
- 禁止增多、删减、修改任何一个字、标点、换行

### 5. 底部链接规则
- 底部只留两个链接：
  1. `https://amruta.today/`
  2. 从中文文档 source 字段提取的 sahaja.live 链接
- 不附加翻译来源说明区块

---

## 工作流

### Step 1: 抓取
- 从 amruta.today 抓取英文原文、标题、链接

### Step 2: 翻译 + 对齐
1. 从 amruta.today 抓取英文原文、标题、链接
2. 去 F盘官方翻译文档中，**只截取与抓取英文对应的那部分中文**
   - 在官方翻译文档中找到与抓取英文对应的段落
   - 只取该英文段落对应的中文段落
   - **禁止截取全部 27 个中文段落**
3. 按三种对齐模式（1:1 / N:1 / 1:N）输出
4. 英文标题翻译：用官方翻译中的对应关键词，没有的用阿里云

### Step 3: 生成邮件 HTML
- 按对齐结构生成 HTML
- 底部只留两个链接

### Step 4: 审核
- 运行审核脚本，所有检查项必须 [OK]

### Step 5: 发送
- 通过 QQ SMTP 发送邮件

### Step 6: Git push
- 推送到 GitHub Pages
